# Cockpit X

Cockpit Opérational Calculation & Knowledge Toolbox — PWA de calculateurs et fiches de connaissances pour pilotes.

## Développement

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Fonctionnalités

- **Calculateurs** : altitude pression, altitude densité, plafond nuageux, triangle du vent, vent traversier/effectif.
- **Connaissances** : types de brouillard, Vx vs Vy, signaux lumineux ATC, décrochages.
- Installable comme app (PWA), fonctionne hors ligne.
